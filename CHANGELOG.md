# Changelog

All notable changes to Zotero Deselect will be documented in this file.

The project follows semantic versioning for release numbers.

## [0.2.8] - 2026-10-25

### Added

- Finder / Windows File Explorer-style click-away deselection in Zotero's item list.
- Clicking the only selected item again can deselect it.
- Blank-space clicks in the collection pane can hide the current collection highlight while keeping its contents displayed.
- GitHub Release distribution and Zotero update feed support.

### Fixed

- Clear the residual blue dotted focus outline after deselection.
- Preserve Zotero's native Cmd/Ctrl/Shift multi-selection behavior.

### Compatibility

- Tested on Zotero 10.0.6 on macOS.
- Manifest compatibility: Zotero 10.0 through 10.0.*.
- Windows and Linux have not yet been verified.
